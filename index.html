Department of Dravyaguna
Sweta Chandana
Botanical Name :

  • Santalum album

    • Family Name :

  • Santalaceae

    • Local Name :

  • White Sandalwood

    • Vernacular Name :

  • Hindi – Safed Chandan

  • English – White Sandalwood

    • Synonyms :

  • Chandana

  • Malayaja

  • Gandha


    • Habitat :

  • Native to India (Especially Karnataka, Tamil Nadu)

  • Grows in dry deciduous forests

  • Requires well-drained soil


    • Morphology :

  • Small to medium evergreen tree 8–12 ml

  • Leaves: Opposite, smooth, green)

  • Flowers: Small, purplish-brown

  • Heartwood: Yellowish, highly aromatic

  • Bark: Dark brown


    • Useful Parts :

  • Heartwood

  • Oil


    • Chemical Constituents :

  • Santalol

  • Sesquiterpenes

  • Volatile oils


    • Actions :

  • Cooling

  • Antiseptic

  • Anti-inflammatory

  • Sedative

  • Aromatic


    • Properties :

  • Rasa: Tikta, Madhura

  • Guna: Laghu, Ruksha

  • Virya: Sheeta

  • Vipaka: Katu


    • Indications :

  • Burning sensation

  • Fever

  • Skin diseases

  • Urinary infections

  • Pitta disorders


    • Dose :

  • Churna: 1–3 g

  • Oil: External use as required


    • Formulations :

  • Chandanasava
